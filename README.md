# QA Automation y CI/CD – Proyecto práctico

Proyecto práctico desarrollado como parte de mi preparación técnica para el puesto de **QA Engineer / QA Automation**

El proyecto está enfocado en el aseguramiento de la calidad del software, la automatización de pruebas, la validación de API REST, las pruebas de rendimiento y la integración continua.

## Objetivos del proyecto

- Desarrollar y validar API REST utilizando Python y Flask.
- Diseñar y ejecutar pruebas automatizadas con pytest.
- Validar respuestas HTTP, estructuras JSON y gestión de errores.
- Realizar pruebas de rendimiento y carga utilizando k6.
- Configurar procesos de integración continua (CI) mediante Jenkins.
- Gestionar el código fuente y el control de versiones con Git y GitHub.

## Tecnologías

- **Python 3.12** – Lenguaje de programación.
- **Flask** – Desarrollo de API REST.
- **pytest** – Automatización y ejecución de pruebas.
- **Git / GitHub** – Control de versiones y gestión del código fuente.
- **Jenkins** – Integración continua y automatización de procesos.
- **k6** – Pruebas de rendimiento y carga.
